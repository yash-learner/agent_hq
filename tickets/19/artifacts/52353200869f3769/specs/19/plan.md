# Implementation Plan: Add support for inserting links in the left navbar

## Overview

Add administrator-configurable custom navigation links via environment variable (`REACT_NAV_LINKS`), allowing healthcare facilities to add documentation links (NABH certification, facility guidelines) to the left navbar without deploying custom plugins. This extends the existing plugin-based navigation injection pattern to support environment-based configuration.

## Architecture Approach

### Configuration Layer

Extend `care.config.ts` to parse and validate `REACT_NAV_LINKS` environment variable:
- Parse JSON array of custom link definitions from `REACT_NAV_LINKS`
- Schema validation with fallback to empty array on parse error or invalid structure
- Each link definition matches `NavigationLink` interface: `{ name, url, icon?, visibility?, target?, children? }`
- Console error logging for invalid JSON with graceful degradation (app continues without custom links)
- Export as `careConfig.customNavLinks` for consumption by navigation components

### Navigation Integration

Modify `src/components/ui/sidebar/facility/facility-nav.tsx`:
- Import `careConfig.customNavLinks`
- Inject custom links into the facility navigation link array generated by `generateFacilityLinks()`
- Position custom links after built-in links and plugin links to avoid conflicts
- Support icon rendering from both CareIcon and Lucide icon sets
- Support `target="_blank"` for external links
- Respect `visibility: false` to hide links conditionally
- Ensure tooltip display when sidebar is collapsed (already handled by `NavMain` component)

### Icon Support

Custom links support icon specification via:
- CareIcon format: `{ type: "care", icon: "d-hospital" }` → renders `<CareIcon icon="d-hospital" />`
- Lucide format: `{ type: "lucide", icon: "ExternalLink" }` → dynamically imports and renders Lucide icon
- Fallback to Avatar with first letter if no icon specified (existing behavior)

### Plugin Compatibility

The implementation preserves plugin navigation injection:
- Plugin links from `careApps.navItems` continue to inject via `pluginNavItems`
- Custom links and plugin links coexist without conflicts
- Render order: built-in links → plugin links → custom links

## Implementation Tasks

1. **Extend care.config.ts**
   - Parse `REACT_NAV_LINKS` JSON string
   - Validate structure (array of objects with required `name` and `url`)
   - Add error handling for invalid JSON with console logging
   - Export `customNavLinks` property

2. **Update facility-nav.tsx**
   - Import `careConfig.customNavLinks`
   - Add custom links to navigation array in `generateFacilityLinks()`
   - Implement icon resolution (CareIcon vs. Lucide)
   - Support `target="_blank"` for external links

3. **Document environment variable**
   - Add `REACT_NAV_LINKS` to `.example.env` with JSON schema example
   - Include examples for internal links, external links with `target="_blank"`, icon specification, and visibility control

4. **Testing**
   - Unit tests for config parsing and validation
   - Component tests for link rendering with various configurations
   - E2E tests for custom link visibility, click behavior, and tooltip display
